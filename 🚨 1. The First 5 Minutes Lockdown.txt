🚨 1. The "First 5 Minutes" Lockdown Script
 
The teaser showed sudo passwdless. If you don't fix this in the first 5 minutes, an enemy team will SSH in, run sudo su, and own your box.
 
Open your terminal and run these exactly:
# 1. Fix the passwordless sudo issue immediately
sudo passwd root       # Set a strong root password
sudo passwd ctf        # Change the default 'ctf' user password

# 2. Check if someone else already logged in as root
last | head -n 10      # See recent logins
who                    # See who is currently logged in

# 3. Backup your services instantly
mkdir -p /tmp/my_backup
sudo cp -r /var/www/html /tmp/my_backup/ 2>/dev/null
sudo cp -r /team /tmp/my_backup/ 2>/dev/null

# 4. Protect the flag from being deleted (Make it immutable)
# Note: This might break the SLA if the checker needs to write to it. 
# Only do this if the flag is static.
sudo chattr +i /flag 2>/dev/null
sudo chattr +i /flag.txt 2>/dev/null
